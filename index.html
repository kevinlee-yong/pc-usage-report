PC 사용량 보고서

Windows에 이미 쌓여 있는 이벤트 로그·레지스트리 기록만 읽어서, 누가·언제·얼마나 PC를 썼는지와 무슨 앱을 썼는지를 HTML 보고서 한 장으로 만들어 주는 무설치 도구입니다. 설치 과정 없이 압축을 풀고 실행하면 끝나며, 결과는 브라우저로 열리는 파일 하나입니다.

ZIP 39KB · EXE 90KB Windows 10 / 11 .NET Framework 4.8 (기본 내장) 관리자 권한 필요 (UAC) 외부 전송 없음 v1.0 · 2026-11-24
실사용 시간 계산
로그인~로그아웃 구간에서 계정 전환·절전 시간을 빼고, 화면을 실제로 쓰던 시간만 남깁니다.
다중 계정 지원
한 PC를 여러 계정이 써도 계정별로 나눠서 계산합니다(관리자 권한으로 실행 시 모두 포함).
자리 비움 제외
입력이 없는 시간·화면 잠금 시간을 실사용에서 빼서 실제 사용 시간에 가깝게 만듭니다.
기간 선택 · 익명화 공유
1주일~1년 중 골라 만들고, 계정명·PC 이름·경로를 지운 공유용 버전도 한 번에 뽑을 수 있습니다.

EXE를 직접 내려받는 링크는 제공하지 않습니다. 브라우저(Chrome·Edge)가 실행 파일(.exe) 직접 다운로드를 악성코드로 간주해 차단하기 때문입니다. 반드시 ZIP 파일을 받아 압축을 푼 뒤 실행하세요.

설치 방법 (4단계 · 1분)

1

ZIP 다운로드

위의 ZIP 다운로드 버튼을 누릅니다. 파일명: PCUsageReport.zip

2

압축 풀기

ZIP 파일을 우클릭 → 모두 압축 풀기. 압축 안의 파일을 직접 실행하지 말고, 먼저 바탕화면 등에 풀어주세요.

3

PCUsageReport.exe 실행 → UAC “예”

풀린 PCUsageReport.exe를 더블클릭합니다. 이 프로그램은 다른 계정의 기록까지 읽기 위해 관리자 권한을 요청합니다. “Windows의 PC 보호” 창이 뜨면 추가 정보 → 실행.

관리자 권한 없이 실행해도 동작하지만, 다른 계정의 앱 기록과 자리 비움 기록은 빠집니다. (보고서 상단에 경고로 표시됩니다.)
4

기간 선택 → 보고서 만들기

1주일 · 2주일 · 3주일 · 4주일 · 1달 · 2달 · 6개월 · 1년 중 하나를 고르면 아래에 실제 계산 범위가 미리 보입니다. 보고서 만들기를 누르면 10~60초 뒤 바탕화면에 PC사용량_보고서_<PC이름>_<시작일>_<종료일>.html 이 생성되고 브라우저로 열립니다.

자리 비움까지 빼려면 — 첫 실행 때 “지금 설정할까요? (Y/N)” 이 나오면 Y. Windows 감사 정책(4800~4803)을 켜서, 입력이 없는 시간과 화면 잠금 시간을 실사용에서 제외합니다. 나중에 PCUsageReport.exe --setup-idle 로 다시 켤 수 있습니다.

다른 사람에게 보여주기 (익명화)

보고서에는 계정 이름·PC 이름·앱 설치 경로가 들어 있습니다. 그대로 보내기 곤란할 때 --anon 으로 만들면 계정명이 사용자 A·B·C 로 바뀌고, PC 이름과 경로가 지워집니다.

만든 HTML은 파일 하나로 완결되어 있어, 카카오톡·메일 첨부나 웹 서버 업로드로 그대로 전달할 수 있습니다.

제거 방법

  1. 압축을 푼 폴더(또는 exe) 삭제
  2. 바탕화면에 쌓인 PC사용량_보고서_*.html 중 필요 없는 것 삭제
  3. 자리 비움 설정을 되돌리려면 관리자 PowerShell에서 감사 정책을 끕니다

레지스트리에는 설정값만 들어 있고, 사용 기록은 저장하지 않습니다.

자주 묻는 질문

왜 EXE를 바로 안 주고 ZIP으로 주나요?

Chrome·Edge가 실행 파일(.exe) 직접 다운로드를 악성코드로 간주해 차단하기 때문입니다. ZIP은 차단되지 않아 이 방식이 가장 안전합니다.

“Windows의 PC 보호” 경고가 뜹니다.

코드 서명 인증서가 없어 생기는 일반적인 경고입니다. 추가 정보 → 실행으로 진행하거나, src/의 소스를 직접 빌드해 쓰셔도 됩니다.

설치되는 프로그램인가요?

아니요. 압축을 풀면 exe 하나이고, 레지스트리에는 자리 비움 설정값만 남깁니다. 서비스나 드라이버를 설치하지 않습니다.

왜 관리자 권한을 요청하나요?

다른 계정의 앱 실행 기록(UserAssist·BAM)과 보안 이벤트 로그(4800~4803)를 읽으려면 필요합니다. 거부해도 실행되지만 그 계정의 앱 기록은 빠집니다.

자리 비움은 어떻게 판단하나요?

Windows 감사 정책의 화면 잠금(4800/4801)·화면 보호기(4802/4803) 기록과, 입력이 없는 시간을 사용합니다. 동영상 재생처럼 입력 없이 보는 시간은 보통 실사용으로 남습니다.

기록이 예전 것부터 비어 있습니다.

Windows 이벤트 로그는 용량이 차면 오래된 것부터 지워집니다. 보고서의 ‘확인 필요’에 그 사실이 표시되며, 6개월·1년처럼 긴 기간은 앞부분이 비어 있을 수 있습니다.

Mac이나 휴대폰에서도 되나요?

아니요. Windows 이벤트 로그를 읽는 도구라 Windows 10/11 전용입니다. 만들어진 HTML 보고서는 어떤 기기에서든 열립니다.

개인정보가 수집되나요?

아니요. 네트워크를 사용하지 않고, 기록은 생성한 HTML 파일에만 남습니다. 공유 전에는 --anon 사용을 권장합니다.
